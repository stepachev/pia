# pia.app — нативное окно-чат pia (macOS 26+)

Сборка и установка: `./build.sh` (→ `~/Applications/pia.app`; `--no-install` — только `build/pia.app`).
- Автозапуск: LaunchAgent `~/Library/LaunchAgents/com.pi-agent.chat.plist` (шаблон — `../launchd/com.pi-agent.chat.plist.template`): при входе запускается `PiaChat --hidden` — без окна, только монитор двойного нажатия правого Shift; KeepAlive перезапускает при падении (⌘Q — выход без перезапуска до следующего входа). build.sh ставит его и перезапускает.
- Окно: двойное нажатие правого Shift, `pia://show`, команда Raycast «pia», `open -a pia`. Esc и переход в другое приложение (NSWorkspace.didActivateApplication чужого bundle id, после 1 с от показа) только прячут окно; причины пишутся в app.log («скрыто: …»). Окно — borderless nonactivatingPanel (без заголовка и «светофора») со своей мягкой тенью (поля 40 pt пропускают щелчки, размер — за край карточки, перетаскивание — полоса 30 pt сверху карточки и пустой фон).
- Вид: непрозрачный фон (светлая тема — белый, тёмная — #1B1B1C), тонкая рамка, поле ввода капсулой (без подсказки; растёт вверх по высоте текста до ~½ окна, радиус 18, полосы прокрутки нет — InputView.swift); отчёты помощников (role report) в окне не показываются.
- Работяги: над полем ввода серая строка «N работяг» (склонение — plural), по щелчку/наведению — список: короткая задача (shortTitle: часть после «:», 2–3 слова) и время работы (workTime: «12 с», «3 мин», «1 ч 05 мин»); готовые («готов») не показываются. Мок: `--helpers N`.
- SwiftPM, таргет PiaChat. Собирается с SDK 26.5 из Command Line Tools: в SDK 27 `@State` — макрос, а плагина SwiftUIMacros в CLT нет.
- Подпись: самоподписанный сертификат «pia local signing» в `signing/pia-signing.keychain-db`, bundle id `com.pi-agent.chat`,
  hardened runtime + `com.apple.security.automation.apple-events`. Требование подписи постоянное (identifier + лист сертификата),
  поэтому разрешения macOS (Универсальный доступ, Запись экрана, Автоматизация) не сбрасываются при пересборке. Не удалять папку signing/.
- Служба: `~/.pi-agent/server.json` (или `PIA_SERVER_JSON=путь` / `--server-json путь`). История — опрос `/api/history` (~1 с, пока окно видно),
  помощники — `/api/state`, отправка — `/api/send` (source: "mac"). Журнал — `app.log`.
- URL: `pia://show`, `pia://hide`, `pia://toggle`, `pia://capture` (как двойной правый Shift). `--hidden` — запуск без окна.
- Sources/PiaChat/Context/ — модуль захвата по двойному нажатию правого Shift. Жест: правый Shift (keyCode 60) — два коротких нажатия (каждое ≤ 300 мс), второе ≤ 350 мс после первого отпускания, срабатывание на втором отпускании; любая клавиша (глобальный монитор keyDown), другой модификатор или левый Shift между/во время нажатий сбрасывают; оба Shift сразу — нет; тройное — одно срабатывание. Логика — чистый автомат `DoubleTapDetector.swift`, мониторы — `ShiftMonitor.swift` (RightShiftDoubleTapMonitor; права: Универсальный доступ, Мониторинг ввода). Снимок окна: сперва обрезаются однотонные поля по краям (ContextScreenshot.contentRect: строка/столбец однотонны, если ≥ 99.6 % пикселей близки к их медиане; рамка окна и скруглённые углы не мешают; запас 12 px; срез ≤ 40 % по каждой оси), затем ужимается до 800 px по длинной стороне (CGContext .high), PNG; если PNG > 300 КБ — JPEG 0.85 (.jpg).
- Текст окна (ContextText.swift → CapturedContext.visibleText, блок «Текст окна:» в asMarkdown): браузеры — JS `document.body.innerText` через AppleScript (Chrome-подобные: нужна их настройка «Разрешить JavaScript из Apple Events», Safari — в меню «Разработка»; у Yab команды execute javascript нет — сразу AX), иначе Accessibility: самая крупная AXWebArea фокусного окна; прочие приложения — AX фокусного окна (AXStaticText/AXTextArea/AXTextField/AXHeading, глубина ≤ 25, ≤ 1 с, фрагменты одной строки склеиваются по координатам); терминалы — последние 200 строк. Очистка: пустые строки, повторы, ≤ 6000 симв. (начало; при выделении — абзац вокруг него). Проверка: `context-check/context-check --app=… | --text-test | --trim-test | --shot=картинка` (PIA_TRIM_DEBUG=1 — края обрезки).
- Тест-цикл без фокуса: `PIA_TEST_CYCLE=1` (скрыть/показать/размер/key → в лог «кнопок=… titled=…»).

Проверка без настоящего разговора: `node test-mock.mjs --config /tmp/pia-mock/server.json`, затем
`PIA_SERVER_JSON=/tmp/pia-mock/server.json PIA_TEST_OFFSCREEN=1 build/pia.app/Contents/MacOS/PiaChat` (крючки — TestHooks.swift).
- Двойное нажатие правого Option (keyCode 61, `Context/OptionMonitor.swift`): окно не активно — показать и вывести вперёд, активно — спрятать (без снимка контекста; снимок — по правому Shift). Жест как у Shift (два нажатия ≤ 300 мс, пауза ≤ 350 мс, любая клавиша/другой модификатор/левый Option сбрасывает, ⌥+символ не срабатывает). По умолчанию ВКЛ; выключить: `defaults write com.pi-agent.chat pia.optionHotkey -bool false` (и перезапуск окна) или `open pia://option-off` / `pia://option-on` (без перезапуска). Нужен «Универсальный доступ» (Системные настройки → Конфиденциальность и безопасность); без него хоткей молчит, окно работает как раньше. Если то же сочетание задано в Raycast — отключите одно из двух.
